### 1. Ethereal Arpeggio Pluck / Harp
* **Role:** Pluck
* **Tone.js Type:** `Tone.PolySynth` (`Tone.FMSynth` or `Tone.Synth`)
* **Register / Note Range:** Mid to High (A3 – E6)
* **Oscillator Configuration:**
  * Type: `triangle` (Carrier) / `sine` (Modulator)
  * Polyphony / Voicing: Polyphonic (8 voices)
  * Harmonicity / Modulation Index: `harmonicity: 2.0`, `modulationIndex: 1.5`
* **Amplitude Envelope (ADSR):**
  * Attack: `0.005s`
  * Decay: `0.45s`
  * Sustain: `0.05`
  * Release: `0.8s`
* **Filter Envelope & Cutoff:**
  * Filter Type: `lowpass` (12 dB/oct)
  * Base Cutoff: `1800Hz`
  * Envelope Amount / Octaves: `2.5`
  * Attack: `0.005s` | Decay: `0.35s` | Sustain: `0.1` | Release: `0.6s`
* **Brightness & Timbre:** Bright, delicate, crystalline, harp/kalimba-like transient
* **Movement & Modulation:**
  * Pitch Mod / Vibrato: `rate: 4.5Hz`, `depth: 0.02`
  * Detune / Unison: `spread: 8 cents`, `count: 2`
  * LFO Destinations: Stereo Pan (LFO type: `sine`, rate: `0.2Hz`, min: `-0.6`, max: `0.6`)
  * Portamento / Glide: `0.0s`
* **FX Chain:**
  1. `Tone.PingPongDelay` (`delayTime: "8n."`, `feedback: 0.35`, `wet: 0.4`)
  2. `Tone.Reverb` (`decay: 3.5`, `preDelay: 0.02`, `wet: 0.45`)

### 2. Warm Sub / Foundation Bass
* **Role:** Bass / Drone
* **Tone.js Type:** `Tone.MonoSynth`
* **Register / Note Range:** Sub-Bass to Low-Mid (E1 – E3)
* **Oscillator Configuration:**
  * Type: `triangle`
  * Polyphony / Voicing: Monophonic
* **Amplitude Envelope (ADSR):**
  * Attack: `0.15s`
  * Decay: `0.8s`
  * Sustain: `0.85`
  * Release: `1.2s`
* **Filter Envelope & Cutoff:**
  * Filter Type: `lowpass` (24 dB/oct)
  * Base Cutoff: `320Hz`
  * Envelope Amount / Octaves: `1.2`
  * Attack: `0.2s` | Decay: `0.5s` | Sustain: `0.5` | Release: `1.0s`
* **Brightness & Timbre:** Deep, warm, smooth, fundamental-heavy
* **Movement & Modulation:**
  * Pitch Mod / Vibrato: None
  * Detune / Unison: None
  * LFO Destinations: None
  * Portamento / Glide: `0.05s`
* **FX Chain:**
  1. `Tone.Filter` (`frequency: 450`, `type: "lowpass"`, `wet: 1.0`)
  2. `Tone.Chorus` (`frequency: 0.5`, `delayTime: 3.5`, `depth: 0.2`, `wet: 0.15`)

### 3. Ambient Evolving String Pad
* **Role:** Pad
* **Tone.js Type:** `Tone.PolySynth` (`Tone.Synth`)
* **Register / Note Range:** Mid (A2 – C5)
* **Oscillator Configuration:**
  * Type: `fatsawtooth`
  * Polyphony / Voicing: Polyphonic (6 voices)
* **Amplitude Envelope (ADSR):**
  * Attack: `1.8s`
  * Decay: `2.0s`
  * Sustain: `0.75`
  * Release: `3.0s`
* **Filter Envelope & Cutoff:**
  * Filter Type: `lowpass` (12 dB/oct)
  * Base Cutoff: `900Hz`
  * Envelope Amount / Octaves: `1.5`
  * Attack: `2.0s` | Decay: `2.5s` | Sustain: `0.6` | Release: `2.5s`
* **Brightness & Timbre:** Dark, warm, airy, soft swell
* **Movement & Modulation:**
  * Pitch Mod / Vibrato: `rate: 0.8Hz`, `depth: 0.05`
  * Detune / Unison: `spread: 20 cents`, `count: 3`
  * LFO Destinations: Filter Cutoff (LFO type: `sine`, rate: `0.1Hz`, min: `600Hz`, max: `1400Hz`)
  * Portamento / Glide: `0.0s`
* **FX Chain:**
  1. `Tone.Chorus` (`frequency: 1.2`, `delayTime: 4.0`, `depth: 0.6`, `wet: 0.5`)
  2. `Tone.Reverb` (`decay: 5.5`, `preDelay: 0.05`, `wet: 0.6`)
