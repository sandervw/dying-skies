* **Role:** Pluck
* **Tone.js Type:** `Tone.PolySynth(Tone.Synth)`
* **Register / Note Range:** Mid to High (C4–C6)
* **Oscillator Configuration:**
  * Type: `triangle` or `pwm`
  * Polyphony / Voicing: Polyphonic (4 voices)
  * Harmonicity / Modulation Index: N/A
* **Amplitude Envelope (ADSR):**
  * Attack: `0.005s`
  * Decay: `0.35s`
  * Sustain: `0.05`
  * Release: `0.4s`
* **Filter Envelope & Cutoff:**
  * Filter Type: `lowpass` (24 dB/oct)
  * Base Cutoff: `800Hz`
  * Envelope Amount / Octaves: `3.5`
  * Attack: `0.005s` | Decay: `0.25s` | Sustain: `0.1` | Release: `0.3s`
* **Brightness & Timbre:** Crisp, glassy, percussive, bright transient
* **Movement & Modulation:**
  * Pitch Mod / Vibrato: `rate: 0Hz, depth: 0`
  * Detune / Unison: `spread: 8 cents, count: 2`
  * LFO Destinations: Filter Cutoff (LFO type: `sine`, rate: `0.1Hz`, min: `600Hz`, max: `1200Hz`)
  * Portamento / Glide: `0.0s`
* **FX Chain:**
  1. `Tone.PingPongDelay` (`delayTime: "8n.", feedback: 0.35, wet: 0.3`)
