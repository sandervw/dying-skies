# Tone.js Sound Spec Sheet

---

### 1. Deep Pulsing Sub-Bass
* **Role:** Bass
* **Tone.js Type:** `Tone.MonoSynth`
* **Register / Note Range:** Sub-Bass (D1 – A1 / ~36 – 55 Hz)
* **Oscillator Configuration:**
  * Type: `triangle` (with slight sine sub-blend)
  * Polyphony / Voicing: Monophonic
* **Amplitude Envelope (ADSR):**
  * Attack: `0.01s`
  * Decay: `0.45s`
  * Sustain: `0.1`
  * Release: `0.5s`
* **Filter Envelope & Cutoff:**
  * Filter Type: `lowpass` (24 dB/oct)
  * Base Cutoff: `90Hz`
  * Envelope Amount / Octaves: `2.0`
  * Attack: `0.01s` | Decay: `0.3s` | Sustain: `0.0` | Release: `0.4s`
* **Brightness & Timbre:** Dark, heavy, muted low-end thud
* **Movement & Modulation:**
  * Pitch Mod / Vibrato: none
  * Detune / Unison: none
  * LFO Destinations: none
  * Portamento / Glide: `0.0s`
* **FX Chain (Ordered signal flow):**
  1. `Tone.Distortion` (`distortion: 0.15, wet: 0.2`)
  2. `Tone.Reverb` (`decay: 1.5, preDelay: 0.01, wet: 0.15`)

### 2. Dark Evolving Resonant Pad / Drone
* **Role:** Drone / Pad
* **Tone.js Type:** `Tone.PolySynth(Tone.FMSynth)`
* **Register / Note Range:** Low-Mid to Mid (D2 – A3)
* **Oscillator Configuration:**
  * Type: `fatsawtooth` (Modulator: `sine`)
  * Polyphony / Voicing: Polyphonic (4 voices)
  * Harmonicity / Modulation Index: `harmonicity: 1.5, modulationIndex: 3.0`
* **Amplitude Envelope (ADSR):**
  * Attack: `2.2s`
  * Decay: `1.8s`
  * Sustain: `0.75`
  * Release: `3.5s`
* **Filter Envelope & Cutoff:**
  * Filter Type: `lowpass` (12 dB/oct)
  * Base Cutoff: `450Hz`
  * Envelope Amount / Octaves: `1.8`
  * Attack: `2.0s` | Decay: `1.5s` | Sustain: `0.6` | Release: `3.0s`
* **Brightness & Timbre:** Warm, ominous, hollow, evolving metallic undertones
* **Movement & Modulation:**
  * Pitch Mod / Vibrato: `rate: 0.2Hz, depth: 0.05`
  * Detune / Unison: `spread: 18 cents, count: 3`
  * LFO Destinations: filter cutoff (LFO type: `sine`, rate: `0.08Hz`, min: `350`, max: `900`)
  * Portamento / Glide: `0.1s`
* **FX Chain (Ordered signal flow):**
  1. `Tone.Chorus` (`frequency: 0.5, delayTime: 3.5, depth: 0.7, wet: 0.4`)
  2. `Tone.FeedbackDelay` (`delayTime: "4n.", feedback: 0.35, wet: 0.25`)
  3. `Tone.Reverb` (`decay: 5.0, preDelay: 0.05, wet: 0.55`)

### 3. Metallic Ethereal Air / Whistle
* **Role:** Percussion / FX
* **Tone.js Type:** `Tone.NoiseSynth`
* **Register / Note Range:** High Frequency Band (~1.8 kHz – 4.5 kHz)
* **Oscillator Configuration:**
  * Type: `pink noise`
  * Polyphony / Voicing: Monophonic
* **Amplitude Envelope (ADSR):**
  * Attack: `1.8s`
  * Decay: `2.0s`
  * Sustain: `0.4`
  * Release: `3.0s`
* **Filter Envelope & Cutoff:**
  * Filter Type: `bandpass` (24 dB/oct, Q: `6.0`)
  * Base Cutoff: `2200Hz`
  * Envelope Amount / Octaves: `1.2`
  * Attack: `1.5s` | Decay: `2.0s` | Sustain: `0.5` | Release: `2.5s`
* **Brightness & Timbre:** Glass-like, airy, distant, resonant hiss
* **Movement & Modulation:**
  * LFO Destinations: pan (LFO type: `triangle`, rate: `0.15Hz`, min: `-0.7`, max: `0.7`)
* **FX Chain (Ordered signal flow):**
  1. `Tone.PingPongDelay` (`delayTime: "8n", feedback: 0.45, wet: 0.4`)
  2. `Tone.Reverb` (`decay: 6.0, preDelay: 0.08, wet: 0.7`)
