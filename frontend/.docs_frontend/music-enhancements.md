# Lock and slip.

*Familiar bits that gradually drift.*

Keep 8-bar chunk, but each time it repeats, swap out only one or two random notes instead of all of them.

Dial the swap chance up for chaos, down for stability.

# Mismatched loop lengths (Eno).

Run 2-4 voices at once, each looping a short random phrase of a different length: 5, 7, and 11 beats.

Phrases almost never line up the same way twice; a few tiny loops create endless variety.
