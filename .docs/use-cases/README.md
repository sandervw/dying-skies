# Use cases

Black-box test script for Dying Skies. A tester needs only a browser and this folder. Every use case is written from the visitor's side: what they do, and what they see or hear. UC IDs are stable; never renumber them.

Actors: **Visitor** (no account), **User** (signed in). Terms follow [the glossary](../glossary.md).

The Sky is one canvas. Stars are found by position, and the static art is judged by screenshot. Controls are found by their labels: "Unmute music", "Mute music", "immersive-mode", "Analytics", "Gallery", "Back", "Save this sky", "Destroy this sky", and "Account/Sign-in".

| Area | File | UC IDs |
|---|---|---|
| Skies | [skies.md](skies.md) | UC-01 to UC-10 |
| Accounts | [accounts.md](accounts.md) | UC-11 to UC-20 |
| Saving, the Gallery, and destroying | [saving.md](saving.md) | UC-21 to UC-28 |

## Not covered

The analytics site's own pages, lock-screen controls on a phone, and how the music sounds.
